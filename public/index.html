Como Integrar (Guia Rápido n8n & API) Exemplos prontos para copiar e colar no nó HTTP Request sem precisar programar
1. Começando — URL base e autenticação

Use o header x-api-key: SUA_CHAVE (ou Authorization: Bearer SUA_CHAVE) em todas as chamadas:

https://liasync.atualyze.com.br/api/v1/openapi.json

Observação sobre WhatsApp: como a Lia Sync usa Evolution API, não há bloqueio de janela de 24h nem necessidade de template aprovado pela Meta para iniciar conversas.

2. Enviar mensagem pelo n8n (POST /api/v1/messages/send)
https://liasync.atualyze.com.br/api/v1/messages/send 
{
  "phone": "5511988887777",
  "message": "Olá! Recebemos seu pedido e já estamos separando."
}
3. Capturar lead ou mover etapa do funil (POST /api/v1/leads & PATCH /api/v1/contacts/{phone})
https://liasync.atualyze.com.br/api/v1/leads 
{
  "phone": "5511988887777",
  "name": "Marina",
  "interest": "Plano Pro",
  "source": "Site",
  "sendGreeting": true
}
4. Ligar / desligar a IA e mover etapa (PATCH /api/v1/contacts/{phone})
https://liasync.atualyze.com.br/api/v1/contacts/5511988887777 
{
  "dealStage": "qualificado",
  "humanMode": true,
  "notes": "Assumido pelo vendedor no CRM"
}
5. Consultar a IA diretamente (POST /api/v1/ai/ask)
https://liasync.atualyze.com.br/api/v1/ai/ask 
{
  "prompt": "Resuma nossos serviços em 2 frases."
}
